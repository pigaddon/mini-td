# 迷你塔防

Godot 4 迷宫式 2D 塔防（多种塔/敌人、科技突破、多地图）。

## 下载 Android 版

- 下载页：https://pigaddon.github.io/mini-td/
- APK 直链：https://github.com/pigaddon/mini-td/releases/latest/download/MiniTD.apk

## 用编辑器运行

1. 安装 [Godot 4.7+](https://godotengine.org/download)
2. 导入本目录的 `project.godot`
3. 按 F5 运行

## 操作

| 操作 | 说明 |
|------|------|
| 左键 | 放置 / 选中塔 |
| 空格 | 开波 / 提前开波拿奖金 |
| P | 暂停 |
| F | 加速 |

## 目录

